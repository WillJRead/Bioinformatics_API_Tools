This project was created a personal development piece to improve my understanding of APIs in the context of genomic medicine. 

Application Programming Interfaces (API) operate via a client sending a request to a server, and the server returning requested data. This is extremely useful in bioinformatics where there are multiple online databases that contain large amounts of genomic data that cannot simply be copied or downloaded.

APIs operate of CRUD (Create, Return, Update, Delete) methods. Typically requests are sent using JSON which means that the server can handle the request despite what coding language the backend was built on.
